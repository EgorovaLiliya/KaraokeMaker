# KaraokeMaker

Android-приложение для занятий вокалом: делает из любого mp3 караоке-версию.

- **Убирает основной вокал**, оставляя бэк-вокал и инструментал (модель MelBand Karaoke на [MVSEP](https://mvsep.com)).
- **Показывает текст строками** в такт песне, как YouTube Music и Яндекс Музыка. Текст берётся из бесплатной базы
  [LRCLIB](https://lrclib.net), а если его там нет — распознаётся нейросетью Whisper по выделенному вокалу.
- **Отсчёт на проигрышах**: перед строкой после длинной паузы показывается обратный отсчёт.
- **Нажатие на строку** перематывает песню к ней с запасом 4 секунды на вдох (запас настраивается).
- **Трансляция на Android TV**: тот же APK ставится на телевизор и открывается там как экран караоке.
  Звук и текст идут с ТВ, а телефон работает как пульт.
- Редактор текста: поиск в LRCLIB, распознавание, выравнивание вставленного текста по вокалу, сдвиг таймингов,
  расстановка меток по ходу песни кнопкой «⏱ Метка».

## Установка

1. Откройте [Releases](../../releases/latest) и скачайте `KaraokeMaker.apk`.
2. Установите его на телефон (разрешите установку из неизвестных источников).
3. Для телевизора поставьте тот же APK на Android TV, например через приложение «Send files to TV»,
   флешку или `adb install KaraokeMaker.apk`.

## Настройка (один раз)

**MVSEP** (удаление вокала):
1. Зарегистрируйтесь на <https://mvsep.com>. Бесплатного аккаунта достаточно, но задачи иногда стоят в очереди.
2. Скопируйте API token из профиля и вставьте его в *Настройки → MVSEP API token*.

**Распознавание текста** (нужно только для песен, которых нет в LRCLIB):
1. Получите бесплатный ключ на <https://console.groq.com> → API Keys.
2. Вставьте его в *Настройки → API-ключ*. Подойдёт и OpenAI: адрес `https://api.openai.com/v1`, модель `whisper-1`.

## Как пользоваться

1. «Добавить песню» → выберите mp3 → проверьте исполнителя и название → «Сделать караоке».
   Можно и просто «Поделиться» mp3 из другого приложения в KaraokeMaker.
2. Подождите 1–5 минут, пока идёт обработка (статус виден в списке).
3. Откройте песню. Переключатель «Минус / Оригинал» внизу.
4. Значок трансляции вверху → выберите телевизор (на ТВ должно быть открыто KaraokeMaker).
   Если ТВ не находится, введите адрес с экрана телевизора.

## Сборка

GitHub Actions собирает APK на каждый push в `main` и публикует его в Releases.
Локально: `./gradlew assembleRelease` (нужен Android SDK).
